SELECTED DELIVERY

Production problems, solved end to end.

Anonymized examples based on systems delivered for a U.S. healthcare organization.

01

Company-wide data foundation

From spreadsheet operations to a governed Azure platform

Challenge

A U.S. Medicare brokerage relied on scattered files and source-specific reporting logic across customers, policies, commissions, agents and calls.

Build

Designed the relational foundation and production pipelines across Azure Data Factory, Databricks, Python, PostgreSQL and reporting marts.

Result

Created a centralized operating model supporting 20+ feeds and more than 2.3 million carrier records.

02

Reusable carrier ingestion

Different files. One repeatable processing pattern.

Challenge

Carrier files arrived with inconsistent schemas, dates, identifiers, tabs and commission structures—making manual processing slow and error-prone.

Build

Standardized source tracking, schema validation, date derivation, upserts, deduplication, audit history and safe reruns across carrier workflows.

Result

Operationalized 11 carrier procedures and a watcher-driven ingestion pattern for new files and historical backfills.

03

Operational event pipelines

High-volume activity data made analysis-ready

Challenge

Call and agent-status APIs required pagination, timezone correction, daily windows, retries and historical reconciliation.

Build

Built checkpointed API ingestion with deduplication, rolling backfills and curated daily KPI models for operations teams.

Result

Processed 600K+ call and status events into reliable reporting foundations for productivity and campaign analysis.
